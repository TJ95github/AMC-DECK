# AMC-DECK

OSCE station deck for AMC Clinical Stage 2.

- **Live:** https://tj95github.github.io/AMC-DECK/
- **Offline backup:** download `offline.html` — one self-contained file, works with no internet and no GitHub. Open it in any browser.
- `cards.json` is the deck data; `index.html` is the app.

301 stations: OG-01–26, MED-01–181, PE-01–94.
